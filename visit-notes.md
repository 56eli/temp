Die Cloud wird für Tanja's eigene Dateien und geteilte Dateien benutzt.

Der primäre Job der Cloud ist Backup von Tanjas internal storage. Das Backup in der Cloud sollte genau dem Backup auf der externen entsprechen.

Es ist kein vollständiges Backup des PC's (wie windows dateien oder steam spiele) aber sonst hauptsächlich Medien.

Sehr speicherfressende Dateien wie große Videos sollen nur auf die externe damit die Cloud nicht gefüllt wird.

Die Dateien die gebackupped werden sind teilweise Dinge die vom Pc runter sollen aber teilweise auch Dateien auf dem PC bleiben sollen

Tanjas Intention ist die folgende:
Tanja will dass neue Dateien die sie auf dem PC ablegt (sprich persönliche Medien order für Urlaub und Co) in der Cloud landen.
Sie macht es selber. Sie würde gerne synchronisieren, hat aber keine Ahnung in welche RIchtung synchronisationen laufen weil der Cloud Dienst sehr undurchsichtig ist.
Tanja macht es gerne manuell, damit die Datenkontrolle hat, weil sie sonst nicht weiß, wo die Dateien landen ob irgendwas gelköscht wird. Sie mag die Cloud funktionswiese nicht was Synchronisation angeht.

Tanja hätte gerne zwei mal das Hochzeitsvideo, also nicht alle Dateien sollten komplett rasiert werden auf eine Datei.
Das Bingo video hätte sie auch gerne zwei mal. Sie sieht ein, dass sie den überblick über die vielen Duplikate verloren hat.

Tanja will das KEINE Datei aus der Cloud auf den PC geladen wird. Sie will es in der Cloud sichern, und sie sagt es macht null Sinn, dass dann die Cloud das auch nochmal auf den Pc läd. Tanja war sich auf dieses Cloudverhalten gar nicht bewusst und ist erzürnt.

Das heißt alle Dateien aus der Cloud, die nun auf dem PC liegen, können gelöscht werden, sofern sie in der Cloud bleiben.

Consider the following:
Original folder A syncs to the Cloud.
Cloud backups on internal storage into folder B.
Tanja is scared that folder A somehow gets deleted in the clean up process which deletes the Cloud files.
However Tanja has no use for folder B.


Assume all folders in the Cloud have actual images. Not just virtual links or empty files.



Consider the following:
Tanja receives Halloween pictures.
She has a full folder of images on PC.
She only wants the most important pictures in the Cloud, to not fill the cloud up so fast. Then she creates a folder in the cloud with the same name, but only with a selection of the images.
She estimates about 15% of folders in the cloud are set up that way (partial clones of internal folders).
